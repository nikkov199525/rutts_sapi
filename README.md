# RU TTS Sapi.

Почти нормальная реализация моста sapi для легчайшего синтезатора ruTTS!

## Описание

Это мост между SAPI и синтезатором `ru_tts`, чтобы голос работал в приложениях, которые  используют sapi в своей  работе. Это читалки текста, скринридеры, в общем, это по сути делает ru tts синтезатором, доступным всем и каждому.
В проекте есть конфигуратор, чтобы можно было править кучу дополнительных параметров. конфигуратор максимально простой.

Ставятся обе разрядности: 32-битный движок нужен JAWS и прочим 32-битным программам, 64-битный — всем остальным.
Настройки лежат в `%APPDATA%\rutts\rutts.ini`.

## Сборка

Всё собирается из исходников: ядро `ru_tts`, `rulex` вместе с базой `rulex.db`, мост и конфигуратор.
Ядро, rulex, LMDB, PCRE2 и libsamplerate подключены подмодулями.

Нужны:

- [LLVM-MinGW](https://github.com/mstorsjo/llvm-mingw) — в `PATH` или в переменной `LLVM_MINGW`
  (`winget install MartinStorsjo.LLVM-MinGW.UCRT`);
- [CMake](https://cmake.org/) 3.24 или новее (подойдёт и тот, что идёт с Visual Studio);
- [Inno Setup 6](https://jrsoftware.org/isinfo.php) — для установщика.

```bash
git clone --recursive https://github.com/nikkov199525/rutts_sapi
```

Дальше одна команда собирает обе разрядности, прогоняет тесты и складывает результат в `out`:

```bash
build_release.cmd
```

- `out\ru_tts` — готовые файлы, разложенные так же, как их ставит установщик:
  `x86\` и `x64\` с движками, общий `rulex.db`, конфигуратор и лицензии;
- `out\Output\rutts_sapi_YYYY.MM.DD_setup.exe` — установщик.

В `build\` остаётся только промежуточная сборка и тесты.

## Отладка

- `tests\integration.cpp` — проверка движка и rulex без регистрации в системе, запускается сборкой.
- `tests\sapi_probe.ps1` — проверка установленного голоса так, как его гоняет скринридер.
- Пустой файл `sapi_trace.log` рядом с `rutts.ini` включает журнал всего, что SAPI-клиент присылает движку.
