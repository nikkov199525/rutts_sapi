# RU TTS Sapi.

Почти нормальная реализация моста sapi для легчайшего синтезатора ruTTS!

## Описание

Это мост между SAPI и синтезатором `ru_tts`, чтобы голос работал в приложениях, которые  используют sapi в своей  работе. Это читалки текста, скринридеры, в общем, это по сути делает ru tts синтезатором, доступным всем и каждому.  
В проекте есть конфигуратор, чтобы можно было править кучу дополнительных параметров. конфигуратор максимально простой.

## Как собрать

Важно: сам синтезатор `ru_tts` и библиотека `rulex` в этом репозитории **не собираются**.  
Их нужно собрать отдельно или взять готовые где- нибудь ru_tts.dll, ru_tts.dll и rulex.db. где и как вы это все достанете я не знаю, но без этого сборка не пройдет.

1. Клонировать репозиторий:

```bash
git clone https://github.com/...

```
2. Перейдите в папку со склонированным репозиторием и подложите файлы вот так:

- `out\ru_tts\lib\x32\ru_tts.dll`
- `out\ru_tts\lib\x64\ru_tts.dll`
- `out\ru_tts\lib\x32\rulex.dll`
- `out\ru_tts\lib\x64\rulex.dll`
- `out\ru_tts\rulex.db`

3. После этого запустить сборку всего этого великолепия:

```bat
build_release.bat
```

4. Готовый установщик появится в:

- `out\Output\rutts_sapi_YYYY.MM.DD_setup.exe`
После этого устанавливаем и пользуемся.
